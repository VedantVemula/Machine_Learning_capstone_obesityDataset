# Machine Learning Capstone on Obesity Dataset

Predicting obesity levels using the UCI "Estimation of Obesity Levels 
Based on Eating Habits and Physical Condition" dataset.

## Tracks
- Regression: predicting Weight (10 algorithms)
- Classification: predicting NObeyesdad, obesity category (Part A: 5 algorithms, Review 1)
- Clustering: added in Review 2

## Setup
pip install -r requirements.txt

## How to run
Open notebooks/regression.ipynb or notebooks/classification.ipynb 
in Jupyter and run all cells top to bottom.
